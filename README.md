# agentgateway on EKS workshops

Hands-on workshops (about 60 minutes each) for deploying [agentgateway](https://agentgateway.dev) to Amazon EKS and exploring its MCP capabilities: routing, dynamic discovery, JWT auth, tool-level RBAC, and the UI.

## Workshops

| Workshop | What you deploy |
|---|---|
| [Open source agentgateway](oss-agentgateway-workshop.md) | agentgateway in Kubernetes mode with its built-in read-only UI. No license required. |
| [Solo Enterprise agentgateway](enterprise-agentgateway-workshop.md) | Enterprise agentgateway with the full UI: tracing dashboards, cost management, and ClickHouse-backed telemetry. Requires a Solo trial license key. |

Both follow the same five-module flow, so you can run either one standalone or do open source first and enterprise after.
